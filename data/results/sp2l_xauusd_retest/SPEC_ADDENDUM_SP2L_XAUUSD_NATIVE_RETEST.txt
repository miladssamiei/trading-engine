continuation hypothesis (original: data/results/sp2l_ablation/SPEC.md,
2026-08-27, run on US500-tick). SP2L was ported from a third-party XAUUSD
M1 bot (SP2L_Advanced_Bot.py) and forced onto US500 because no gold data
existed then. This addendum removes that substitution: the EXISTING
pipeline logic runs on native XAUUSD tick data with the ORIGINAL gold
parameters. Not a new hypothesis, not a rule change:
- evaluate/sp2l_phase1.py, evaluate/sp2l_step3.py: LOGIC VERBATIM; the
  re-test derivatives sp2l_phase1_xauusd.py / sp2l_step3_xauusd.py (in
  this directory) differ ONLY by the input path, the dollar-denominated

  tooling; only earned if gates pass).

3. MECHANISM, SESSIONS, CONVENTIONS (all identical to the frozen SPEC.md)

Setup detection (10 clauses, SIGNED bodies, spike-candle-spanning gap),
pending machine (single pending, break+risk+MAX_SL kill, trend/EMA/ADX
filters, session gating), second-entry toggle, E-XTM/E-CLS dual
conventions, LON/NY/ALL24 session variants with DST-aware zoneinfo walls,
NY-date day blocks, 0.01 trade-grid price normalization. The gold tape's
daily structure (24h with 17:00-18:00 NY break + weekends) feeds the same
natural-gap handling the US500 daily halt did (SPEC sec 2).

4. PHASE 1 (gates identical to GATE.md)

48 configurations = {EMA, TREND, ADX, SECOND} x {LON, NY, ALL24} on the
full 2020-01..2026-09 M1 tape. Stage-A light-touch subset reported first.
- G1: count(MFE>=t) > count(MAE>=t) at ALL of t in {0.10%, 0.15%, 0.20%},
  under BOTH E-XTM and E-CLS.
- G2: >= 150 first-entry signals.
- Multiplicity honesty identical (both conventions; Phase 1 only admits
  to Step 3; PGAP sensitivity cannot admit).
If no configuration passes: NULL result, STOP.

5. STEP 3 (only for Phase-1 passers; protocol identical to GATE.md)

TP_R grid {0.5, 0.75, 1.0, 1.5, 2.0}, SL = pre-spike extreme
(rule-fixed). Phase A first-crossing reconstruction (exploratory).
Phase B occupancy re-simulation + walk-forward: BURN-IN = everything
before 2022-01 (26 months; the original burned only 2021 because its
tape began 2021-01 - equivalent everything-before-first-fold structure,
declared), folds 2022H1..2026H1 (9 half-year folds, the final fold ends
2026-09 - the tape end; the original final fold ended 2026-05 at ITS
tape end), select by trailing expectancy (>= 20 trailing trades else
TP_R=1.0).
Walk-forward gates (gross-of-cost, as frozen): G1 expectancy>0 AND
Sharpe>0; G2 >= 150 trades; G3 positive in >= 4 of 5 calendar years
(2022..2026) AND best year < 60% of profit. CONFIRMATION requires the
gates under BOTH E-XTM and E-CLS; E-NEXT remains the tightening-only
step-4 buildability gate. Metrics remain gross-of-cost (bid tape); the
REPORT additionally states after-cost context using the MEASURED XAUUSD
floor ($0.41 full-tape / $0.399 cash median spread, Q4) WITHOUT changing
any gate.
