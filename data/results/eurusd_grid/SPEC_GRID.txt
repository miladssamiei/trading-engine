Signals and chronology
At each real H1 bucket open use only previously completed H1 bars. Qualifying volume V(t-1)>V(t-2)>V(t-3), strictly. Long if C(t-1)>EMA5(t-1); short if C(t-1)<EMA5(t-1); equality is flat. Enter at the first actual M1 open of current bucket, logging any delay from bucket boundary. At most one order per H1 bucket, one basket at a time, all positions in a basket share direction. If flat a qualifying signal starts a basket with size 1.0. If occupied, opposite signals are ignored, and same-direction signals add only if current BID open is at least 0.00300 adverse from last position's BID reference entry, with tolerance 1e-12 price units. Size of added order is previous size times 1.5. The same fixed spread on both long entry quotes means this BID-reference spacing equals comparing executable ASK to ASK. No skipped grid levels are backfilled. Add only one next level even if an opening gap crosses multiple 30-pip steps. No depth/size cap, stop, time exit, reversal exit or prop guard is invented.

Basket target and fixed cost
1 pip = 0.0001 EURUSD. Use base-unit pip equivalents, not average pips per current lot. At BID price P, gross = direction*sum(size*(P-entry_bid))/0.0001; cost = 0.3*sum(size); net = gross-cost. This is equivalent to ASK=BID+0.00003 for long entry and short exit, BID for short entry and long exit. Charge that round-trip cost exactly once per individual position, scaled by size, including open-basket liquidation marks. At each real H1 close, after that hour's possible entry/addition, close the entire basket only if net>30.0 base-unit pip equivalents (strict exceeds with 1e-9 numerical tolerance). Execute at the H1 BID close proxy, all positions simultaneously; log actual last M1 observation and nominal bucket end. No intrahour target fills or synthetic-hour target fills. There is no new basket at that same close. Spread is a fixed floor, not historical variable ASK, and financing/commission beyond it/margin are not modeled.

Hidden-risk measurements
Main absolute floating drawdown = max(0,-minimum net liquidation PnL since basket entry), in base-unit pip equivalents. Use actual H1 lows for longs / highs for shorts, as well as opens/closes; all positions are fixed from the first real minute through the hour, so the adverse H1 extremum exactly captures the adverse M1 price extremum for that basket inventory. Also save close-marked peak-to-trough net floating drawdown as a distinct metric; do not claim unknowable high/low order from OHLC. Update risk after every grid addition, including its immediate incremental spread. Record global/worst-basket drawdown across both closed and still-open baskets, worst-hour timestamp, maximum depth, maximum total size and maximum individual size.

Underwater time
H1 decisions cannot identify exact seconds underwater. Use the original real M1 closes to estimate it. Count one observed minute for each real M1 close with net<0 (1e-9 tolerance). Primary calendar-underwater estimate assigns that minute's close-mark state to the interval from its M1 timestamp to the next observation or H1 bucket end; carry the last observed sign across synthetic hours and delayed next-bucket opens. This includes weekends/data gaps at the last known mark and is an estimate, not observed intragap price. Report both calendar-underwater hours/days and observed-minute-underwater hours, plus elapsed hold time and first underwater-to-final-exit span. The average before closing is over closed baskets only; the unresolved basket gets its own accrued time and risk. No actual quote or trade is manufactured by this time accounting.
