SECTION 0. SCOPE, PREMISE, AND STATUS

0.1 Premise: ftmo_pairs_us500_usa30 (#24) showed the swap-free US500/USA30
pairs counterfactual passes FTMO Phase 1 at Multiplier 5.0 from the March
2021 list start (pass 2021-05-11, 42 trading days, peak daily loss 3.72%,
max trailing DD 3.13%) - a SINGLE-PATH result on 18 trades. This study
quantifies how much of that pass is luck: (A) start-date luck via rolling
fresh challenges on every trade entry date, and (B) sequencing luck via
10,000 seeded Monte Carlo shuffles of the 18-trade list. Same frozen trades,
same economics, no new signals.

0.2 This is NOT new strategy research and NOT an FTMO qualification
(ftmo10k_qualification_v1 stays INCOMPLETE). The pairs_us500_usa30 (#19)
FAIL verdict stands untouched. downstream_model_allowed=false,
live_execution_allowed=false regardless of verdict.

SECTION 1. DATA AND ECONOMICS (frozen inputs, unmodified)

1.1 Trade list: data/results/pairs_us500_usa30/pairs_trades.csv, exactly 18
rows (entry_date,exit_date,direction,z_entry,z_exit,beta,lots30,p500_entry,
p500_exit,p30_entry,p30_exit,hold_nights,exit_reason,gross_usd,
spread_cost_usd,swap_usd,net_usd), 2021-03-12..2026-06-23. Verified totals:
gross +$1,572.62, spread -$30.77, swap -$5,510.00.
1.2 SWAP-FREE OVERRIDE: per-trade realized USD = (gross_usd - spread_cost_usd)
x Multiplier 5.0. The verified spreads (0.51 pt US500, 2.28 pt USA30) are
embedded in spread_cost_usd and RETAINED; swap is dropped (= 0.00). Verified
swap-free total at 1x: +$1,541.85 (= net_usd + swap_usd).
1.3 Multiplier 5.0 (#24's optimal): lots500 = 5.0, lots30 = lots30_col x 5.0
per trade; every dollar quantity below scales x5.
1.4 D1 marks, EXACTLY the #24 convention: US500 leg =
momentum_multihorizon/us500c_d1.csv (server-date OHLC); USA30 leg = D1
aggregation of the #24-cached restamped Athens-wall M5 tape
(ftmo_pairs_us500_usa30/usa30_m5_eet.csv) grouped by wall date (first open /
max high / min low / last close). Simulation grid = the INTERSECTION of both
grids; all 36 entry/exit dates must be present in it. Declared caveat: the
Athens wall clock carries <= 1 h DST-rule skew vs the US500 server clock.
1.5 Execution model: entry at the D1 close of the entry date, marked at the
CSV's own entry prices (p500_entry, p30_entry - the #19 model closes);
realized PnL is the FROZEN CSV value (1.2), never reconstructed. A
reconstruction audit (grid-close recomputation of gross_usd) is reported; it
does not feed the simulation.
1.6 Floating marks per exposed day d: fl(d) = M x [dir x (c500_d - p500_entry)
+ (-dir) x (c30_d - p30_entry) x lots30_col]. WORST floating uses the
pessimistic #24 convention: SIMULTANEOUS adverse D1 extremes of both legs
(low500/high30 for LONG_SPREAD; high500/low30 for SHORT_SPREAD). Exposure
days are entry+1 .. exit (entry is at the close, so the entry day itself has
no exposure; the exit day's adverse extreme is counted BEFORE the close
realization - the #26-style declared pessimism).
1.7 FTMO Phase-1 economics: initial $10,000; target +8% = $10,800 judged on
REALIZED balance (tasking definition; deviation from #24's close-mark equity
pass - declared, slightly stricter since floating gains cannot trigger a
pass); Max Daily Loss = 5.0% of the prior server-day 00:00 realized balance
anchor (frozen #23/#24 convention; approximates FTMO's fixed $500 at start);
Max Loss = static $9,000 floor on worst floating equity. A breach on the
pass day voids the pass (pessimistic same-day rule). Failure attribution:
FLOOR if worst floating <= $9,000, else DAILY (floor takes precedence when
both trigger the same day).

SECTION 2. STRESS TEST A - ROLLING CHALLENGE START DATES

2.1 Start dates: EVERY trade entry date in the 18-trade list (18 starts,
2021-03-12..2026-05-04).
2.2 Per start date s: fresh $10,000; day-1 anchor = $10,000; trade sequence
= trades with entry >= s in original order on the common D1 grid; simulate
forward; stop at PASS (first day where realized balance >= $10,800 with no
breach that same or earlier day) or FAIL (first breach day); UNRESOLVED if
neither before tape end.
2.3 Metrics: Rolling Start Pass Rate (primary = passes / all 18 starts;
resolved-only also reported), Average + Median Days to Pass (trading days
from s to pass day), failure split DAILY vs FLOOR (%), unresolved count,
per-start outcome table, median/p95 peak drawdown of passing runs.

SECTION 3. STRESS TEST B - MONTE CARLO SEQUENCING (10,000 shuffles)

3.1 Generator: numpy default_rng(20260921), 10,000 uniform random
permutations of the 18-trade list.
3.2 Sequencing convention (declared, identical to #26): trades are
re-sequenced BACK-TO-BACK on consecutive common-grid trading days; trade j
occupies its original holding span (exit_idx - entry_idx, min 1) with entry
at its block's first day close, floating exposure on the following span
days carrying the trade's ORIGINAL daily adverse/close path relative to its
original entry prices, and realization at the block's last day close; the
next trade starts the following grid day. Per-trade risk structure is
preserved; cross-trade chronology is deliberately destroyed. This is a
sequencing study, not a calendar simulation.
3.3 Same stop rules as Test A from a fresh $10,000 (day-1 anchor $10,000);
UNRESOLVED if the shuffled list ends before pass/breach.
3.4 Metrics: Monte Carlo Pass Rate (primary = passes / 10,000; resolved-only
also), Median Peak Drawdown, 95th-percentile Peak Drawdown (Peak Drawdown =
max peak-to-trough of the worst-path equity series, % of peak), median
days-to-pass of passing runs, failure split.

SECTION 4. GATES (verbatim in GATE_PAIRS_STRESS.txt)

G-S1 DATA INTEGRITY: both mark grids load; exactly 18 trades; all entry/exit
dates present in the common grid; swap-free realized total (gross_usd -
spread_cost_usd) equals $1,541.85 within $0.01 with the 0.51/2.28 pt spreads
retained; all 18 rolling starts simulated with pass + fail + unresolved =
18.
G-S2 ROLLING PASS RATE: rolling-start pass rate over RESOLVED runs >= 50%.
G-S3 MONTE-CARLO ROBUSTNESS: MC pass rate over RESOLVED runs >= 50% AND
95th-percentile peak drawdown < 10.0%.
OVERALL: PASS iff G-S1..G-S3 all PASS. FAIL is a complete, final answer: the
#24 Multiplier=5.0 pass is start-luck/sequencing fragile.

SECTION 5. HONESTY RULES

5.1 The pairs trade list is frozen; no trade, date, direction, ratio, or PnL
is edited. Realized PnL comes from the CSV; D1 paths only create floating
marks.
5.2 Pessimistic conventions: SIMULTANEOUS adverse D1 extremes of both legs
(very pessimistic for a spread - true same-instant spread behavior is
milder); exit-day extreme counted before the close; same-day breach voids a
pass; realized-balance pass semantics; unresolved runs are non-passes in the
primary rates.
5.3 The offline D1-close marks vs the #24 EA fills differ (fill-vs-model
drift in #24: median -$7.02 per pair from overnight-gap execution + Dow
spread); the Athens restamp skew; and the MC block sequencing convention are
declared limitations, not hidden choices.
5.4 No claim of FTMO qualification; no re-opening of the #19 FAIL; the
single-path #24 verdict is context, not evidence here.
