1.3 Q3 — DAY-CLOSE RULE: SYMMETRIC TOTALS. The day closes for new

realized (consecutive or interspersed, identical treatment both
sides), matching the unambiguous loss-side statement.

1.4 Q4 — INDECISION FILTER: body/range < 0.10. body = |close-open|,
range = high-low of the ENTRY-TRIGGER candle. This is an
INTERPRETATION, not a verbatim rule (the video gives no number), in

1.5 Q5 — TRADING WINDOW: derived with THIS PROJECT'S verified
DST-aware epoch->America/New_York machinery, anchored to the verified
cash open, NOT to the presenter's manual Iran-time arithmetic. Entry
window = NY wall minutes [570, 870) = 09:30 to 14:30, i.e. cash open
plus 5 hours. Rationale: Iran (UTC+3:30, no DST) 17:00-22:00 maps to
09:30-14:30 NY only during US DST; a fixed-Iran-clock reading would
drift the window one hour in winter. Cash-open anchoring is the
faithful reading of "trade the US open" and is DST-safe by
construction (a cash day is defined by its 09:30 wall bar).

1.6 I-6 — CONSERVATIVE-MODE ENTRY (INTERPRETATION; the transcript's
examples are the only source): AGGRESSIVE mode enters at the breach
tick (level fill). CONSERVATIVE mode demands the additional
confirming close: the trigger candle must CLOSE beyond the violated
level, and entry occurs at that close. The wick-through alone (the
flip's most permissive form) is NOT sufficient in conservative mode.

1.7 I-7 — WICK-BREACH CLOSE-INSIDE CANDLES: a candle that closes
inside the base's extremes but wicks beyond one of them makes NO
state change when no pending exists (it cannot arm — the arming rule
explicitly excludes opposite-extreme breach, wick or body — and it
cannot become the new base, having violated an extreme).

1.8 I-8 — BASE FROZEN WHILE PENDING: rolling base updates (T3/T5
below) apply only in the no-pending state. While pending is armed,
the base changes only via the T1 cancel/reset transition.

1.9 I-9 — SAME-M1-BAR PROBE+BREACH: if one M1 bar contains both the
probe (beyond R.high for a short) and the breach (beyond R.low), the
intra-bar order is unknowable offline: NO ENTRY from that bar (the
bar still marks the probe as done). The MT5 Model=4 phase measures
what true ticks do differently.

1.10 I-10 — NEUTRAL EXITS: filter exits and forced 15:55 exits count
as neither win nor loss for the day-close tallies. For the mode
machine, a "losing trade" = ANY closed trade with realized net
points < 0 (including negative neutral exits).

1.11 I-11 — SIZING: fixed 2.5 lots = $100 risk (1% of the fixed
$10,000 base) / 40.00-pt stop / $1-per-pt-per-lot. No compounding
(the video's percentage-of-growing-account sizing is NOT simulated;
declared deviation, project no-compounding convention). Ring arms
size analogously: lots = 100 / stop_points.

1.12 I-12 — NO OVERNIGHT HOLDS: any open position is force-closed at
the OPEN of the 15:55 M1 bar (wall 955), project convention.

1.13 Ambiguities are NOT bugs: every transition not specified above
is pre-resolved here. Implementation bugs (code that contradicts
this SPEC) are fixed and the affected stage re-run in full with the
fix disclosed (the scalping-screen RSI-sign-bug precedent); the SPEC
and GATE are never edited after numbers are seen.

SECTION 3 — THE BASE-CANDLE STATE MACHINE (BINDING OPERATIONALIZATION)

3.0 Definitions (per cash day; everything resets at the start of
each cash day):
- B = current base candle (open/high/low/close of one M5 candle).
- pending = {direction DOWN|UP, reference candle R} or none. R is
  the directional-close candle whose high/low define the flip levels.
- Inside(C,B): C.high <= B.high AND C.low >= B.low (no wick beyond
  B's extremes).
- CloseBeyond(C,B): C.close > B.high OR C.close < B.low.
- Down-close vs B: C.close < B.close; up-close: C.close > B.close;
  flat: equal.
- Tick breach of a level L: a trade STRICTLY above (below) L.
  Offline reconstruction walks M1 bars (sec 3.3); the MT5 Phase-D EA
  uses real ticks.

3.1 Per-day initialization: state = NO_BASE. The first completed
in-window M5 candle (start minute in [570,870)) becomes B; state =
BASE.

3.2 Candle-close transitions, evaluated at each completed in-window
M5 candle C (tick-phase events inside C are processed as they occur,
sec 3.3; then C's close is classified in the listed precedence):
  T1 CANCEL/RESET (pending armed): if pending = DOWN (mirror UP)
     and CloseBeyond(C,B): pending = none; B = C. [The confirmation
     candle closed beyond the base without a completed flip: the
     setup cancels and C itself becomes the new base.]
  T2 RESET (no pending): if CloseBeyond(C,B): B = C; pending = none.
  T3 ARM DOWN: if no pending, NOT CloseBeyond(C,B), C.high <= B.high
     (no breach of the base high, wick or body — the source's
     explicit condition; C.low MAY breach B.low), and C.close <
     B.close: pending = DOWN with R = C; ADDITIONALLY, if
     Inside(C,B) then B = C (rolling tighten: "a new base is set
     whenever a candle closes without violating the base"; if C
     wicked below B.low the base is NOT updated — I-7).
  T4 ARM UP (mirror): no pending, NOT CloseBeyond(C,B),
     C.low >= B.low, C.close > B.close: pending = UP with R = C;
     if Inside(C,B) then B = C.
  T5 FLAT INSIDE: no pending, Inside(C,B), C.close == B.close:
     B = C (rolling update, no arm).
  T6 NO-OP: any other close-inside candle (wick breaching an
     extreme without arming, or a non-directional close with a wick
     breach): NO state change (I-7).
  While pending is armed, B is frozen except via T1 (I-8).

3.3 Tick phase — flip monitoring, for pending = DOWN (mirror UP).
Walk M1 bars strictly after R's completion, in time order:
  P1 PROBE: an M1 bar m with m.high > R.high sets probe_done.
  P2 SAME-BAR GUARD: if m.high > R.high AND m.low < R.low, the
     intra-bar order is unknowable offline: NO entry from m (I-9);
     m still sets probe_done.
  P3 FLIP TRIGGER: an M1 bar m with m.low < R.low, probe_done
     already set by an EARLIER bar, and not the P2 case, is the
     ENTRY-TRIGGER bar; the trigger candle T is the M5 candle
     containing m.
  P4 AGGRESSIVE FILL: entry price = R.low (level fill); if m opens
     below R.low, fill at m.open (gap-through convention). Entry
     timestamp = m's time.
  P5 CONSERVATIVE FILL: no entry at m; at T's close, if T.close <
     R.low: entry at T.close; else NO entry (setup consumed).
  P6 ELIGIBILITY: entry timestamps must have wall minute <= 870 on
     the cash day. Ineligible (past cutoff), day closed (sec 5.2),
     or position already open (Stage B/C/D occupancy): the signal is
     SKIPPED, not queued; pending = none (setup consumed); the
     machine continues from the current B.
  P7 BREACH WITHOUT PROBE: an M1 bar with m.low < R.low while
     probe_done is false and m.high <= R.high is NOT an entry; the
     pending state survives until a candle-close transition (T1, or
     re-arming on later closes) resolves it.

3.4 The machine runs continuously through the window on every cash
day, including while a position is open (skipped signals are logged
for audit). Stage A samples ALL signals (no occupancy — declared
approximation, the VWAP-R:R/scalping-screen convention); Stage B/C/D
apply occupancy.

3.5 DISTINCTNESS FROM ALL PRIOR HYPOTHESES (required statement):
- NOT ORB (#1): no opening-range levels; a rolling base candle
  updates continuously through the session, vs one fixed morning
  range.
- NOT trend-pullback (#6) and NOT Al Brooks H1/H2 (#10/#11): no
  trend filter of any kind (no EMA, no ADX, no leg counting) — a
  pure candle-close-and-reversal state machine.
- NOT SP2L (#5): no spike/gap ratio, no ADX/EMA60 context filter.
- NOT any P1-P8 scalping-screen pattern: none tracks a rolling base
  or a probe-then-reverse flip sequence.

3.6 AUDIT TRACE: every T1-T6 and P1-P7 event appends one row to
base_candle_state_log.csv (ny_date, m5_bar_start, event_code,
fields). The state machine is complex enough that this trace is a
required deliverable, not a debug aid.


SECTION 4 — ENTRY BOOKKEEPING AND THE INDECISION FILTER

4.1 Trigger candle T = the M5 candle containing the entry-trigger
M1 bar (both modes).
4.2 Filter (at T's close): body = |T.close - T.open|; range =
T.high - T.low. range <= 0 is degenerate and FILTERED (tallied).
FILTERED iff body/range < 0.10 (Q4).
4.3 AGGRESSIVE: enter per P4; if T is filtered, EXIT IMMEDIATELY at
T.close (filter exit; neutral classification per I-10).
4.4 CONSERVATIVE: enter only if T.close is beyond the violated level
(P5) AND T is not filtered; entry at T.close.
4.5 Occupancy (Stage B/C/D): one position at a time; signals while
holding are skipped, not queued. Stage A: no occupancy.


SECTION 5 — MONEY-MANAGEMENT DAY MACHINE (Stage B/C/D; NOT applied
in Stage A)

5.1 Reset at each cash day start: mode = AGGRESSIVE; wins = 0;
losses = 0; day_closed = false.
5.2 Classification and day close: a trade resolved at the TARGET
increments wins; at the STOP increments losses; filter exits and
forced exits increment neither (I-10). After each closed trade, if
wins >= 3 OR losses >= 3 (Q3, totals) then day_closed = true: no
further entries that day. The closing trade is already flat
(occupancy), so no liquidation is implied.
5.3 Mode machine: after each closed trade, realized R is measured in
units of the 40.00-pt risk unit (target = +2.0R, stop = -1.0R, other
exits = realized_points/40, signed). If realized net points < 0
(any exit type — I-10): mode = CONSERVATIVE. Else if day cumulative
R >= 0: mode = AGGRESSIVE. Else: mode unchanged. First trade of the
day is always AGGRESSIVE (5.1).
5.4 Sizing (I-11): binding arm = fixed 2.5 lots; ring arms lots =
100/stop_points; $1/pt/lot; fixed $10,000 base, no compounding.
5.5 Exits (binding arm): stop = fill +/- 40.00 pt, target = fill
-/+/ 80.00 pt (short/long). The exit walk follows M1 bars from the
fill timestamp (entry bar inclusive): first-crossing order decides;
same-bar both-level ambiguity => STOP FIRST (conservative); bar-open
gap through a level => fill at the open; forced exit at the OPEN of
the 15:55 M1 bar (wall 955); if the tape ends earlier, exit at the
last available bar's close (tallied); never overnight (I-12).
Validation invariants asserted per trade: stop outcome => adverse
excursion >= stop distance; target outcome => favorable excursion >=
target distance; forced exit => neither level crossed on the walk.


SECTION 6 — STAGE A: EXIT-FREE SIGNAL QUALITY (gate A1)

6.1 Population: every AGGRESSIVE-fill flip entry (P4 fill
definition) with eligible timestamp (sec 2.7) on a cash day, after
warmup; no occupancy; no exits simulated.
6.2 Direction-native MFE/MAE from the execution timestamp over the
next 60 minutes of M1 bars (truncated at data end if shorter).
First-bar E-XTM convention (SP2L, scalping screen): on the fill M1
bar, MFE = max(close - entry, 0) for longs (mirrored shorts), MAE =
max(entry - low, 0) (mirrored); full high/low on subsequent bars.
6.3 Binding threshold set (ATR-scaled, scalping-screen convention
for comparability): t in {0.50, 0.75, 1.00} x ATR14(T) (trigger M5
candle, continuous tape, sec 2.3). Descriptive alongside: fixed t in
{0.10, 0.15, 0.20}% of entry price.
6.4 Statistic e_i = (MFE_i - MAE_i) / ATR14(T).
6.5 GATE A1 (all three clauses required):
  (i) n >= 150 eligible signals;
  (ii) count(MFE >= t) > count(MAE >= t) at EVERY binding threshold;
  (iii) day-block bootstrap P(mean(e) <= 0) <= 0.20, resampling DAY
       MEANS with replacement (10,000 draws, seed 20260903; the
       Bollinger-MR gate convention).
Failing A1 = STOP, null result, no R:R stage.
