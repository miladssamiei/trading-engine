CHIHAB-STYLE RANDOM FOREST + PROBIT HOURLY CROSS-ASSET ADAPTATION - PREDECLARED SPEC - 2026-09-27
Paper: Chihab et al., Algo-Trading Strategy for Intraweek Foreign Exchange Speculation Based on Random Forest and Probit Regression, Applied Computational Intelligence and Soft Computing (2019), DOI 10.1155/2019/8342461, https://onlinelibrary.wiley.com/doi/10.1155/2019/8342461. The article studies intraweek FX with RF/Probit agreement for entry and either negative warning for exit. This study transfers that architecture to the user's hourly GC/NQ/ES proxy setup and is not an exact reproduction of the paper's assets, horizon, features or original reported performance.
Inputs: GC=data/results/xauusd_onboarding/xauusdtick_m1.csv, NQ=data/results/virgin_assets/ustech_m1.csv, ES=data/results/vwap_2021_2026/us500tick_m1.csv. Bid-only M1 CFD-derived prices, complete available periods; no native CME quote/tick/roll data. Build an epoch-aligned continuous H1 OHLC grid by fieldwise forward-fill. Indicators may use filled hours but model observation t must be a REAL H1 bar. Historical training labels require both t and t+1 H1 bars REAL, avoiding synthetic unchanged-price labels. A test prediction may be scored only when t+1 is REAL; score eligibility never feeds its features or signal. Target y_t=1 if H1 close[t+1]>H1 close[t], else 0 (ties count DOWN). Feature F_t uses only completed H1 bars through t.
Frozen features: exactly eight columns: (close-SMA20)/close, (close-SMA50)/close, RSI14, MACD(12,26) line/close, MACD(12,26,9) signal/close, MACD histogram/close, Bollinger(20,2) width/SMA20 using population std(ddof=0), and Wilder ADX14. RSI uses Wilder averages; zero-loss/gain conventions RSI=100/0 and both zero=50. MACD EMAs use adjust=False. Require 50 prior H1 bars and finite features. No feature-selection search, model-family swap or post-hoc threshold adjustment. Train-only StandardScaler mean/std transforms the eight features; zero-variance columns use scaler's standard treatment.
Frozen walk-forward schedule: rolling six UTC calendar months of training and one subsequent UTC calendar month of prediction, first test after six months from the tape's first calendar month, then every month through tape end. Training observations have t within the six-month window and t+1 H1 close timestamp strictly before the test month's first instant. All training data and scaler fits precede the test month. Test predictions on real H1 observations in that month with finite F_t. Save fold date boundaries, train/test/scored counts and hash. Never train on a label whose realization lies inside the test month. No fitting on held-out folds. Require both classes and >=200 training labels per fold; fail rather than switch models if unmet.
Models: RandomForestClassifier(n_estimators=64,max_depth=5,min_samples_leaf=25,max_features='sqrt',random_state=42,n_jobs=1), class label from P(UP)>=0.5. Probit regression is statsmodels Binomial GLM with probit link and intercept, fit by IRLS with maxiter=100 on standardized training features, class label from P(UP)>=0.5. A failed/nonconverged fit aborts the artifact rather than silently choosing another model. Neither probability threshold nor model parameters are tuned on test outcomes.
Accuracy: On scored out-of-sample hours with real t+1 H1 close, report RF accuracy, Probit accuracy, both-agree accuracy and agreement coverage, train-majority-class baseline accuracy, class-1 base rate, fold counts and year-by-year accuracy. Both-agree predictions are the only directional entry votes; disagreements are flat when no position. Accuracy is measured at the signal H1 close, not at the M1 trade fill.
Execution: Convert every out-of-sample prediction at completed real H1 hour t into an action at the next available REAL M1 open with timestamp >= end of hour t. Report gap-to-open hours; no artificial M1 bar is tradable. Each asset has one open position maximum, and CFD/Futures execution are separate runs using the same frozen out-of-sample predictions. When flat, enter long only if both labels 1, short only if both labels 0. While long, exit at an action open if either model labels 0; while short, exit at an action open if either model labels 1. Do not reverse at the same open. If models disagree with a flat book, remain flat. No structural stop, target or daily close was specified, so none is invented. At tape end, any position is OPEN_END with last-close mark and excluded from closed-trade gate/statistics. Signal actions with no next M1 open are dropped.
Costs and guard: CFD GC .41/NQ 1.00/ES .51 price-unit round trips, no prop guard. Futures proxy GC .13/NQ .39/ES .30, plus the requested per-position open-equity retrace guard at 6.0*ATR14 measured on the completed H1 signal bar at entry. Long entry Ask=Bid open+cost, exit Bid; short entry Bid, exit Ask=Bid exit+cost; cost counted once. Guard Peak_Open_Equity starts at zero net and tracks favorable real M1 high/low. For each M1, test its adverse extreme against the previous peak minus 6*entry ATR; on breach fill at the guard level or worse M1 open, classify PROP_LIQUIDATION. Only after the M1 survives update peak from favorable extreme. On an M1 beginning with a model warning exit, execute that exit at its open before any intraminute guard. This is a per-position proxy, not a firm account-wide trailing threshold. No swap or financing charge; count overnight positions. There are six independent environment/asset executions.
Statistics and gates: For all six rows report closed trades, net price-unit expectancy/total, unannualized per-trade Net Sharpe, net win rate, exact PROP_LIQUIDATION and warning exit counts, year-by-year net and signs, and 10,000-sample moving-block bootstrap P(mean net<=0) with five-trade blocks/seed 20260927. Report the accuracy-to-execution gap as agreement OOS accuracy minus realized trade win rate (percentage points), with an explicit warning that the two denominators differ; also provide average correct/incorrect prediction counts and coverage so accuracy is not described as PnL. Per-row gate requires >=150 closed trades, positive net expectancy, positive Net Sharpe, MBB p<=0.05, and positive closed-trade net in each complete OOS calendar year 2021-2025 for GC/NQ or 2022-2025 for ES. Overall pass requires all six rows. This is a strict research gate; a null result is complete. Walk-forward forecasts are genuinely out of sample for model fitting, but historical architecture/feature choices remain exposed to prior research, and no native executable quote stream or firm account rule is validated.
