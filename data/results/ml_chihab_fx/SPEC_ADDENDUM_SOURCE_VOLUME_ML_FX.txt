PRE-RUN SOURCE QUALIFICATION ADDENDUM - 2026-09-27
A two-day GBPUSD Dukascopy-node CLI probe without -v returned 1,440 Sunday M1 rows, including closed-market flat minutes. Repeating the same period with -v -vu units returned 119 observed bars with strictly positive volume, beginning near the Sunday FX reopen. Therefore every full GBPUSD/EURGBP CLI download MUST add -v -vu units and the parser MUST require a volume column and volume>0. Never use no-volume flat-bar output for training, signals or execution. The existing EURUSD source is a documented tick-derived M1 BID export with positive tick_volume and no synthetic no-tick minutes. This addendum precedes source acquisition, evaluator code and model execution; all original SPEC/GATE rules remain in force.
